iPad einrichten · Safari + YouTube

Installiere das vorbereitete Script einmal in Userscripts. Danach kannst du Videos über YouTube hinzufügen und im Tracker bezahlen.

  1. Userscripts aus dem App Store installieren.
  2. In der Dateien-App unter Auf meinem iPad einen Ordner Tracker-Scripts erstellen. In der Userscripts-App über Set Userscripts Directory diesen Ordner auswählen.
  3. Hier Safari-Script herunterladen antippen. Im Safari-Downloadmenü die Datei habit-tracker-youtube.user.js anzeigen. In der Dateien-App lange darauf drücken → Bewegen → Auf meinem iPad → Tracker-Scripts. Der Dateiname muss auf .user.js enden.
  4. Einstellungen → Apps → Safari → Erweiterungen → Userscripts aktivieren. Bei älterem iPadOS steht Safari direkt unter Einstellungen. In Safari Userscripts auf gogei0.github.io und auf www.youtube.com erlauben; bei mobilen Links auch m.youtube.com. Im Erweiterungsmenü das Script aktivieren.
  5. Hier im Abschnitt Cloud Sync dieselbe Projekt-URL, denselben öffentlichen API-Schlüssel und denselben privaten Sync-Code wie auf dem PC eintragen. Die beiden Automatiken zunächst auslassen → Verbindung speichern → Aus Cloud laden. Coins und Habits prüfen, danach beide Automatiken aktivieren und speichern.
  6. Tracker neu laden → Shop → YouTube → Safari verbinden. Anschließend YouTube in einem zweiten Safari-Tab öffnen. ⋮ → Kaufen legt das Video mit deinem Preis im Shop ab. Erst Kaufen im Tracker zieht Coins ab und schaltet das Video frei.

Zuerst den vorhandenen Cloud-Stand laden. Tracker und YouTube als normale Safari-Tabs verwenden. Bereits gekaufte Videos bleiben freigeschaltet, auch wenn du sie aus „Ansehen“ entfernst.
